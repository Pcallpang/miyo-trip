# 홍보물 3종

야르미요의 여행 플래너(https://miyo-trip.vercel.app/) 배포용 자료.
색·폰트·캐릭터는 모두 앱에서 그대로 가져왔고, 앱 화면은 목업 그림이 아니라
실제로 띄워 찍은 스크린샷이다.

### 이미지에 주소를 넣지 않는 이유

인스타에서는 글자로 박힌 주소가 클릭되지 않는다. 넣어 봐야 손으로 옮겨 적어야
하고, 주소가 바뀌면 이미지를 통째로 다시 만들어야 한다. 그래서 안내는
**프로필 링크**로 하고, 이미지는 마지막 장의 **댓글 유도('미요')** 하나만
시킨다. 블로그 글에는 그대로 두었다 — 거기서는 링크가 실제로 눌린다.

### 릴스에 소리가 없는 이유

일부러 뺐다. 릴스는 인스타 앱 안에서 정식 음원을 얹는 쪽이 저작권도 깨끗하고
도달에도 유리하다. 업로드할 때 **음악 → 트렌딩 음원**에서 고르면 된다.
템포가 밝은 곡(120BPM 안팎)이 컷 전환과 잘 맞는다.

## 만드는 과정 (다시 뽑을 때)

```
python stitch.py     # 캡처 조각 → shots/*.png (폰 화면 780×1680)
python carousel.py   # → carousel/*.png
python reels.py      # → 프레임 585장 렌더 후 ffmpeg 인코딩
                     #   (길이는 SCENES 합에서 나오고 파일명에 반영된다)
```

`stitch.py`는 `_capture.html`이 브라우저에서 찍어 둔 조각을 잇는다. 창 높이가
607px뿐이라 840px짜리 폰 화면이 한 번에 안 들어가서, 2배로 그린 뒤 세 조각으로
나눠 찍고 여기서 붙이는 방식이다. 앱 화면을 새로 찍어야 할 때만 다시 돌리면 된다.

ffmpeg 경로는 `reels.py` 위쪽 `FFMPEG` 상수에 박혀 있다(winget 설치 위치).

## 올릴 때 참고

- **캐러셀 1번 슬라이드가 곧 썸네일**이다. 피드에서 보이는 건 이것뿐이라 여기서
  안 잡히면 나머지 6장은 안 읽힌다.
- 릴스는 **첫 2초가 전부**다. "카톡방에 흩어져 있나요?"가 그 역할이라 앞에 다른
  인트로를 붙이지 않는 게 좋다.
- 두 캡션 모두 **첫 두 줄**만 펼치기 전에 보인다. 그 안에 핵심이 들어가 있다.
- 해시태그는 30개까지 되지만 10~15개가 무난하다.
