# 캐러셀 게시글 (인스타 피드)

세 버전 중 하나를 골라 쓰면 된다. 내용은 같고 길이와 말투만 다르다.

**공통 원칙**
- 인스타는 **첫 두 줄**만 펼치기 전에 보인다. 세 버전 모두 그 두 줄에 훅을 넣었다.
- 캐러셀은 **저장(북마크)**이 잘 먹히는 형식이다. 그래서 마지막에 저장 유도를 넣었다.
- 프로필 링크를 미리 `miyo-trip.vercel.app`로 바꿔 두고 "프로필 링크"로
  안내하는 편이 낫다. 캡션 안의 주소는 인스타에서 클릭이 안 된다.

---

## A. 기본 — 스토리텔링 (추천)

가장 길지만 "왜 만들었는지"가 들어가 있어 공감·저장률이 가장 높을 구성이다.

```
여행 일정, 앱 하나로 끝. 🧳
(넘겨서 보세요 →)

지난달 오사카 6박 7일 다녀왔는데
여행은 즐거웠고 준비가 지옥이었습니다.

일정은 카톡방 저 위 어딘가,
예산은 폰에서 안 열리는 엑셀,
준비물은 머릿속.

그래서 결국 하나 빠뜨렸어요.
110V 변환 플러그… 🙃

여행 앱을 안 찾아본 게 아닙니다.
그런데 대부분 가입부터 하라고 하고,
앱을 깔라고 하고,
쓸 만해지면 결제하라고 하고,
비행기 안에서는 열리지도 않더라고요.

그래서 제가 쓸 걸 하나 만들었습니다.

① 일정
시간·장소·메모를 일차별로.
일차마다 도시를 따로 정할 수 있어서
경유하는 일정도 날씨가 제대로 붙습니다.

② 경비
출발 전 결제와 현지 지출을 따로 봅니다.
현지 통화로 넣으면 원화로 자동 환산돼요.
환율은 자동으로 받아 오고 직접 고칠 수도 있습니다.

③ 준비물
기본 목록이 들어 있습니다.
제가 빠뜨렸던 것들이 전부 여기 있어요.

로그인 없음 · 설치 없음 · 광고 없음 · 공짜
데이터는 서버가 아니라 내 폰 안에만 저장됩니다.

샘플 여행(제 오사카 일정)이 통째로 들어 있어서
바로 눌러 보실 수 있어요.

저장해 두었다가 다음 여행 짤 때 꺼내 쓰세요 🔖
궁금한 거 있으면 댓글로 '미요'라고 달아주세요 💬

🔗 프로필 링크
```

## B. 짧은 버전 — 훑고 지나가는 피드용

읽는 데 10초. 기능보다 "공짜·무가입"을 앞세운다.

```
여행 일정, 앱 하나로 끝. 🧳
가입도 설치도 결제도 없습니다.

일정 · 경비 · 준비물 · 날씨를 한 곳에.
현지에서 쓴 돈은 원화로 자동 환산되고,
비행기 안에서 인터넷 없어도 열립니다. ✈️

여행 앱 켤 때마다 로그인하기 싫어서
그냥 직접 만들었어요.

샘플 여행이 들어 있어서 바로 눌러 볼 수 있습니다.
저장해 두고 다음 여행 때 꺼내 쓰세요 🔖

궁금한 거 있으면 댓글로 '미요'라고 달아주세요 💬
🔗 프로필 링크
```

## C. 정보형 — 기능 위주, 담백하게

여행 정보 계정 톤. 내 이야기를 빼고 기능만 전달한다.

```
로그인 없이 쓰는 여행 일정 앱 🧳
(넘겨서 기능 보기 →)

📅 일정
일차별 타임라인. 시간·장소·메모.
일차마다 도시를 따로 지정할 수 있어
경유·다국가 일정도 날씨가 정확합니다.

💸 경비
출발 전 결제와 현지 지출을 분리해서 기록.
현지 통화 입력 → 원화 자동 환산.
환율 자동 조회, 수동 수정 가능.

🎒 준비물
기본 체크리스트 제공. 항목 직접 추가 가능.

🏨 숙소 · 📋 정보
숙소는 날짜별로, 메모·표는 직접 만들어 첨부.

―

✅ 회원가입 없음
✅ 설치 없음 (홈 화면에 추가하면 앱처럼 사용)
✅ 오프라인 동작 — 기내에서도 열립니다
✅ 무료, 광고 없음
✅ 데이터는 기기 안에만 저장

동행자에게는 링크 하나로 일정 전체를 넘길 수 있습니다.

저장 🔖 해두시면 다음 여행 때 쓰기 좋아요.
궁금한 점은 댓글로 '미요'라고 남겨 주세요 💬

🔗 프로필 링크
```

## 해시태그

캡션 맨 아래에 붙이거나, **첫 댓글에 따로 다는 편**이 캡션이 깔끔해서 낫다.

```
#여행플래너 #여행일정 #여행일정표 #여행준비 #여행준비물
#여행앱 #여행경비 #해외여행 #일본여행 #오사카여행
#여행팁 #여행스타그램 #여행계획 #무료앱
```

여행지를 바꿔 올릴 때는 `#오사카여행 #일본여행` 자리에 그 여행지 태그를 넣으면 된다.
