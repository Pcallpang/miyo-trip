# 릴스 게시글 (인스타 릴스)

`reels/reels-18s.mp4`와 함께 올릴 글. 세 버전 중 하나를 고르면 된다.

**캐러셀 캡션과 다르게 쓴 이유**

릴스는 **영상 안에 이미 자막이 다 들어가 있다.** 캡션에서 기능을 또 나열하면
같은 말을 두 번 하는 셈이라 잘 안 읽힌다. 그래서 캡션은 영상이 못 담은 것
(만든 이유, 링크, 댓글 유도)에 집중하고 캐러셀보다 짧게 잡았다.

```
지난달 오사카 6박 7일 다녀오면서

```

## B. 아주 짧은 버전 — 영상에 다 맡기기

영상 자막이 충분하니 캡션은 거들기만 한다. 릴스에서 가장 무난한 길이다.

```
여행 앱 켤 때마다 로그인하기 싫어서
그냥 직접 만들었습니다 🧳

가입 없음 · 설치 없음 · 공짜
비행기 안에서도 열립니다 ✈️

궁금하면 댓글로 '미요' 💬
🔗 프로필 링크
```

## C. 댓글 유도형 — 도달을 노릴 때

질문으로 닫아 댓글을 유도한다. 댓글이 붙으면 릴스는 더 퍼진다.

```
여행 준비하다가 뭐 하나씩 꼭 빠뜨리지 않나요? 🧳

저는 지난달 오사카에서 110V 변환 플러그를 빠뜨렸습니다.
편의점에서 제값 주고 다시 샀어요 🙃

그래서 일정·경비·준비물을 한 곳에 모아 두는 걸
그냥 하나 만들었습니다.
가입도 설치도 없고 공짜예요.

여러분은 여행 가서 뭐 빠뜨려 보셨어요?
댓글로 알려주시면 준비물 목록에 넣어 둘게요 👇

그냥 궁금하신 분은 댓글에 '미요'라고만 달아주셔도 돼요 💬
🔗 프로필 링크
```

## 올릴 때 체크리스트

- **음원을 반드시 얹을 것.** 영상은 무음으로 만들었다. 인스타 앱 편집 화면에서
  **음악 → 트렌딩** 중에 고르면 된다. 템포가 밝은 곡(120BPM 안팎)이 컷 전환과
  잘 맞는다. 무음 릴스는 도달이 눈에 띄게 떨어진다.
- **커버(썸네일)는 1~2초 지점**으로 잡는 게 좋다. "여행 일정, 아직도 카톡방에
  흩어져 있나요?" 자막이 다 떠 있는 구간이라 프로필 격자에서도 읽힌다.
  마지막 CTA 화면을 커버로 쓰면 훅이 사라져서 손해다.
- **'페이스북에도 공유' 끄기** — 계정을 나눠 쓴다면.
- 릴스는 **첫 2초가 전부**다. 영상 앞에 인트로나 로고를 덧붙이지 말 것.
- 영상 마지막에 **"댓글로 '미요'"** 를 띄워 두었다. 댓글이 달리면 하나하나
  답을 달아 주는 게 좋다 — 댓글 수와 대댓글은 릴스가 더 퍼지는 데 직접 영향을 준다.
