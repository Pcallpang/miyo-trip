# 오사카 여행 대시보드 — 설계 문서

작성일: 2026-07-26

## 목적

기존 엑셀(`오사카 여행일정.xlsx`)에 정리된 오사카 여행 일정을 여행 중 모바일에서
쉽고 빠르게 확인할 수 있는 대시보드 앱으로 만든다. 여행은 2026-07-28(화) ~
2026-08-03(월), 6박 7일, 2인.

## 범위 (Scope)

**포함:**
- 모바일 세로 화면 우선의 단일 페이지 대시보드
- 오프라인 동작 (인터넷 없이 열림)
- 날짜별 시간대 타임라인, 고정 정보(숙소/시간표/경비/준비물/팁)
- 가벼운 편집: 준비물 체크, "뭐먹지" 미정 항목 메모 — **폰에만 저장(localStorage)**

**제외 (명시적):**
- 서버/클라우드 동기화, 두 폰 간 공유
- 로그인/계정
- 지도 임베드, 실시간 데이터(날씨/환율 API)
- 지출 실시간 추적/합산 편집 (경비는 읽기 전용 표로만 표시)

## 형태 / 기술

- **자체 완결형 정적 웹앱**: 단일 `index.html` + 내장 CSS/JS. 외부 CDN 의존 없음.
- 여행 데이터는 JS 객체(JSON 구조)로 코드에 내장 → 네트워크 없이 즉시 렌더.
- **PWA**: `manifest.json` + 서비스워커(`sw.js`)로 홈화면 추가 및 오프라인 캐싱.
  (기존 `AI_PT` 프로젝트와 동일한 PWA 패턴을 따른다.)
- 배포 불필요. 파일을 폰에서 열거나 홈화면에 추가하면 됨. (원할 경우 나중에 정적 호스팅 가능.)

## 화면 구성 (위 → 아래 스크롤)

### 1. 상단 요약 헤더
- 여행 제목, D-day 카운터 (오늘 기준)
- 기간: 2026-07-28 ~ 08-03 (6박 7일)
- 숙소: 포포인츠 플렉스 바이 쉐라톤 오사카 신사이바시
- 총 경비: 약 2,612,367원 (2인 합계)

### 2. 날짜 탭 바
- 1~7일차 가로 스크롤 탭. 각 탭에 날짜 + 요일 + 한 줄 테마.
- 탭 선택 시 해당 일차 타임라인으로 스크롤/전환.
- 오늘 날짜에 해당하는 탭 자동 하이라이트 + 초기 선택.

### 3. 일차별 타임라인 카드
각 일차마다:
- 헤더: N일차 · 날짜(요일) · 테마 · 비고(예약 상태 등)
- 시간대별(08:00~21:00) 항목을 세로 타임라인으로 렌더.
- 셀이 비어 있는 시간대는 생략.
- "저녁 뭐먹지 / 점심 뭐먹지" 등 **미정 항목은 강조 스타일** + 메모 입력 필드.

### 4. 고정 정보 섹션 (접기/펼치기 아코디언)
- 🚄 라피트 시간표 (간사이↔난바 왕복)
- 🏨 숙소 정보 (체크인 15시 / 체크아웃 11시, 6박)
- 🎒 준비물 체크리스트 (체크 상태 localStorage 저장)
- 💰 경비 내역 (카테고리별 표, 읽기 전용, 합계 표시)
- 💡 팁 (면세 방법, 준비물 메모 등)

## 저장 (localStorage)
- 키 예: `osaka-trip:packing`(체크된 준비물 배열), `osaka-trip:memo:<day>-<time>`(식당 메모).
- 데이터 스키마 버전 키를 두어 향후 구조 변경에 대비.

## 원본 데이터 참조

엑셀 시트 4개: `여행일정`(시간대별 상세), `라피트 시간표`, `유니버셜 지도`(빈 시트),
`여행경비`. 파싱된 전체 내용은 구현 시 `오사카 여행일정.xlsx`에서 재추출한다.

## 성공 기준
- 폰 브라우저에서 인터넷 없이 열리고, 오늘 일정이 바로 보인다.
- 7일 전체 일정·시간표·경비·준비물을 스크롤/탭으로 3초 안에 찾을 수 있다.
- 준비물 체크와 식당 메모가 앱을 닫았다 열어도 유지된다.

## 테스트 방침
- 데이터 렌더: 각 일차/시간대 항목이 누락 없이 표시되는지 육안 + 항목 수 검증.
- 저장: 체크/메모 입력 후 새로고침 시 유지되는지 확인.
- 오프라인: 네트워크 끈 상태에서 로드 확인.
- 모바일 뷰포트(예: 390px)에서 가로 스크롤 없이 레이아웃 확인.
